# IA_Aulas

Repositório de aprendizado de máquina em Python.

## Pré-requisitos

- Python 3.11.9
- `pip`

## Como usar

1. Criar o ambiente virtual:

```powershell
python -m venv .venv
```

2. Ativar o ambiente virtual:

```powershell
.venv\Scripts\activate.ps1
```

3. Instalar as dependências:

```powershell
pip install -r "requirements.txt"
```

## Como executar os exemplos

Substitua o caminho pelo arquivo que você quer testar.
O caminho que leva ao dataset pode, e provavelmente será, diferente.

## Observações

- Certifique-se de estar no diretório raiz do projeto (`c:\projetos\GitHub\IA_Aulas`).
